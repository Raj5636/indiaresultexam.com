Sample JSON Data

Click the buttons above to load sample data or use your own JSON with these fields:

Basic Fields:

  • title - Main title
  • organization - Organization name
  • officialWebsite - Official website URL
  • websiteName - Website name (e.g., Sarkari Result)

Date & Fee Fields:

  • applicationBegin - Start date
  • lastDate - Last date
  • examDate - Exam date
  • feeGeneral - General category fee
  • feeSCST - SC/ST category fee

Advanced Fields:

  • recruitmentPosts - Array of multiple posts with postName, totalPost, startDate, lastDate, notificationLink
  • links - Array of important links with name and url
  • howToApplySteps - Array of application steps
